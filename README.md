# ai-playground

A simple terminal-based AI hobby app.

## Setup

### 1. Create Virtual Environment

```sh
python -m venv .venv
```

### 2. Activate Virtual Environment

**PowerShell:**
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. Install The Application

```sh
python install -e .
```

### 3. Run The Application

```sh
ai-playground
```
